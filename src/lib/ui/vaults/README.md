# Protocol and curator logos for the Vaults screen

Each company's own mark, to identify it beside its vaults. Downloaded
21 Nov 2026; file name = the slug the backend sends. They sit on the light
logo plate, so these are the versions drawn for light backgrounds.

- `morpho.svg`: Morpho's butterfly, from brand.morpho.org.
- `aave.svg`: Aave's purple mark, from Aave's brand kit (aave.com).
- `gauntlet.png`: Gauntlet's mark, from its brand kit (gauntlet.xyz).
- `galaxy.svg`: Galaxy's mark, from the inline logo on galaxy.com, in black.
- `clearstar.svg`: Clearstar's ring mark, from clearstar.xyz.
- `steakhouse.svg`: Steakhouse Financial's icon, as Morpho's curator listing serves it.
- `bitwise.png`: Bitwise's white wordmark on black, from bitwiseinvestments.com.
- `keyrock.png`: Keyrock's K mark, taken from Morpho's curator listing
  (keyrock.com was unreachable); swap for an official file when possible.
