# Company logos for the Home news

Each company's own mark, used to identify it next to its news. Downloaded
21 Nov 2026, unaltered unless noted. File name = the slug the backend sends.

- `aave.svg`: logomark (purple) from Aave's brand-asset zip, aave.com/brand.
- `chainlink.png`: chain.link's web clip icon.
- `coinbase.png`: Coinbase icon via Wikimedia Commons (coinbase.com blocks downloads).
- `crossmint.png`: crossmint.com apple icon.
- `dtcc.svg`: dtcc.com favicon.
- `galaxy.png`: galaxy.com apple touch icon.
- `kraken.svg`: Kraken's icon from its CMS (assets-cms.kraken.com).
- `metamask.svg`: metamask.io favicon.
- `moonpay.svg`: moonpay.com icon; its dark-mode rule (which turns it white) removed so it stays purple.
- `securitize.svg`: securitize.io favicon.
- `uniswap.svg`: Uniswap logo via Wikimedia Commons.
- `visa.svg`: Visa wordmark (2021) via Wikimedia Commons.

They sit on a light plate (`--logo-plate`) so each reads in both looks.
