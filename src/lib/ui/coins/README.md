# Coin logos

The issuers' official token logos, copied unaltered:

- `usdc.svg`, `eurc.svg`: Circle's brand kit, "Token Logo" (https://www.circle.com/pressroom)
- `cirbtc.svg`: Circle's cirBTC icon, exactly as Circle's own testnet faucet
  (https://faucet.circle.com) draws it, taken from the faucet's code on
  21 Nov 2026: the paths and gradient are unaltered, written out as a file.
- `usdt.svg`: Tether's "Logo Formatted for Use in Circular Displays" (https://tether.to/en/media)

Both issuers require the logos to be used as supplied, not altered, and only
to refer to their tokens. Circle's minimum digital size for the token logo is
32 px tall; AssetBadge never draws them smaller.
